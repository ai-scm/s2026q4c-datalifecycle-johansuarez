# Data Lifecycle — Etapas 3 y 4 - Johan Suarez

## 3. Limpieza de datos (Data Cleansing)

Esta etapa consiste en preparar los datos antes de analizarlos, identificando y corrigiendo errores, eliminando duplicados y transformando la información a formatos consistentes. Su objetivo es mejorar la calidad de los datos para obtener resultados confiables.

**Actividades principales:**
- **Validación:** detectar errores, datos incompletos y duplicados.
- **Estandarización:** unificar formatos, fechas y tipos de datos.
- **Transformación (ETL):** extraer, transformar y cargar información.
- **Catalogación:** organizar metadatos para facilitar la búsqueda y clasificación.

**Servicios AWS:**
- **AWS Glue:** automatiza procesos ETL.
- **AWS Glue Data Catalog:** almacena metadatos y esquemas de los datos.
- **Amazon EMR:** procesa grandes volúmenes de información.
- **Amazon SageMaker Ground Truth:** facilita el etiquetado de datos para Machine Learning.

## 4. Análisis y visualización de datos (Data Analytics & Visualization)

Esta etapa busca convertir los datos preparados en información útil para tomar decisiones. El análisis permite identificar patrones, tendencias y realizar predicciones, mientras que la visualización presenta los resultados mediante gráficos, reportes y dashboards.

**Actividades principales:**
- **Exploración:** consultar información mediante SQL y filtros.
- **Análisis:** identificar patrones, tendencias e indicadores.
- **Visualización:** representar resultados mediante gráficos y dashboards.
- **Predicción:** utilizar Machine Learning para anticipar comportamientos.

**Servicios AWS:**
- **Amazon Athena:** permite consultar datos en S3 utilizando SQL.
- **Amazon Redshift:** almacén de datos para análisis a gran escala.
- **Amazon QuickSight:** crea dashboards y visualizaciones interactivas.
- **Amazon SageMaker:** permite desarrollar modelos de Machine Learning.
